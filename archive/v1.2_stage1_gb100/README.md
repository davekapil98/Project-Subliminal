# Archived v1.2 Stage 1 GB100/Isaac workflow

This directory is a read-only historical snapshot of the superseded v1.2
custom-Isaac data-generation workflow. It is not part of the active v1.3
package, tests, configuration, documentation or execution path.

Do not run these launchers against production credentials or treat the old
tests as evidence for a v1.3 gate. The fully operational original is also
preserved in Git history at commit `4055186`.

The active Stage 1 is public dataset registry, acquisition, validation and
canonicalization. See `README.md`, `docs/stage0.md` and
`docs/legacy_v12_isaac.md` at the repository root.
